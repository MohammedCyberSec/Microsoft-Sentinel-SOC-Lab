# Microsoft-Sentinel-SOC-Lab

This repository documents a cloud-based Security Operations Center lab that I am currently building using Microsoft Sentinel. It will contain the architecture, detection rules, simulated attacks, and investigation notes produced as the lab develops.

## Status

This project is in progress. Content is added only once it has genuinely been built, tested, or investigated.

## Structure

architecture/ documents the design of the lab environment. detections/ contains KQL-based detection rules as they are developed. attack-simulations/ describes simulated attacks used to test detections. investigations/ contains notes from investigating alerts generated in the lab. screenshots/ contains supporting screenshots of the environment and findings. reports/ contains summary reports of completed work.

## Skills being developed

Microsoft Sentinel, KQL, SIEM, incident response, threat hunting, and MITRE ATT&CK mapping.
